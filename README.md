# Sanal Gardırop

Kendi gardırobumu dijitalleştirmek için yaptığım bir Flutter uygulaması.
Gardırop, şifonyer ve askılık kısımlarına gerçek fotoğraflarını ekleyip fotoğraf üzerinden dolap/çekmece
kısımlarına dokunarak kolayca kıyafetlerimi görüntüleyip yönetebiliyorum.

## Özellikler

- Gardırop/şifonyer/askılık fotoğrafları üzerinde özel dokunma alanları
  tanımlama (yüzdeye dayalı koordinat sistemi)
- Kıyafet ekleme: kategori, marka, beden, mevsim, notlar
- Hava durumuna göre günlük tutma ve dereceye göre filtreleme
- Kombin oluşturma (üst/alt/ayakkabı + ekstra parçalar), favorileme

## Kullanılan teknolojiler

- Flutter / Dart
- Riverpod (state management)
- Drift (SQLite veritabanı)
